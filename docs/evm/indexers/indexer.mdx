# EVM Indexer API

The EVM Indexer indexes all EVM transactions, traces, accounts, blocks, and logs for Telos EVM. It also indexes derived data such as token balances, NFTs, approvals & transfers.

Use the Teloscan API documentation for the network you want to query. For REST v2 requests, use the same explorer hostname and the `/api/v2` path.

- [Mainnet API documentation](https://www.teloscan.io/api-docs)
- [Testnet API documentation](https://testnet.teloscan.io/api-docs)

The examples below document the legacy indexer API. Use the current Teloscan API documentation for REST v2 request paths and filters.

## Topics filter

Two routes implement a filter by topics:

- `/contract/{ADDRESS}/logs`
- `/event/{EVENT}/logs`

Using the `topics` field of those routes, this filter allows you to find rows by topics.

#### Single topic
`{"topics[1]": {"_eq": "0x077511a636ba1f10551cc7b89c13ff66a6ac9344e8a917527817a9690b15af7a"}}`

#### Multiple topics

`{"_or": [{"topics[1]": {"_eq": "0x077511a636ba1f10551cc7b89c13ff66a6ac9344e8a917527817a9690b15af7a"}}, {"topics[1]": {"_eq": "0x0a24ea634Ce1f105E2cc7b89c13ff66a6ac9344e8a917527817a9690b15af7a"}}]}`

#### Available operators

- _and
- _or
- _ne
- _eq
